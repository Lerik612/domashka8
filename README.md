# Домашнее задание к работе 8
## Условие задачи:
Представить блок-схему с блоком Повторение. Calculate a^n
## 1. Алгоритм и блок-схема
1. Начало
2. Объявить переменные: a (основание, вещественное), n (степень, целое), result (результат, вещественное), i (счетчик цикла, целое)
3. Ввести значение a
4. Ввести значение n
5. Задать начальное значение результата: result = 1.0 (Важно: именно 1, так как мы умножаем)
6. Задать начальное значение счетчика: i = 1
7. Проверка условия (Начало цикла): i <= n ?

   • Если «Нет» (условие ложно): перейти к шагу 11.
 
   • Если «Да» (условие истинно): перейти к шагу 8.
 
8. Вычислить новое значение результата: result = result * a
9. Увеличить счетчик: i = i + 1
10. Вернуться к шагу 7
11. Вывести значение result
12. Вывести значения a и n 
13. Конец

## 2. Реализация программы
```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
int main() {
	setlocale(LC_ALL, ".UTF-8");
	double a;
	int n;
	double result = 1.0;
	printf("Введите основание а: ");
	scanf("%lf", &a);
	printf("Введите степень n: ");
	scanf("%d", &n);
	for (int i = 0; i < n; i++) {
		result = result * a;
	}
	printf("Результат: %lf\n" , result);

	return 0;
```
